Appendix

Quick-reference for all 33 Draft commands. Syntax shown is for Claude Code; Cursor uses the same /draft:command syntax (it reads the native plugin structure), Copilot uses draft command (no slash), and Gemini uses natural-language @draft prompts.

Command surface: 4 primary workflow commands + 5 intent routers dispatching to 24 specialist leaf commands. Prefer the 5 routers for grouped access.

Deterministic helpers

Beneath the 33 commands sit 56 shell helpers in scripts/tools/. Graph wrappers (graph-callers.sh, graph-impact.sh, hotspot-rank.sh, cycle-detect.sh, mermaid-from-graph.sh) fail loud: gq_run requires a .rows array, so shapeless {} is source:"unavailable" with a non-zero exit — not “no callers / no cycles / no edges”.
